# ツンデレ小悪魔メフィーの黙って強くなりなさいよっ！

小悪魔メフィーが、あんたの癖を読んで強化を押し付けてくる弾よけアクション。
攻撃は自動。あんたは動いて、よけるだけ。

スマホでもパソコンでも、ブラウザですぐ遊べます。1回3分ほど。

**遊ぶ：https://kome0824.github.io/damatsuyo/**

## 遊び方

1. 敵の弾と体当たりをよけながら、フェーズ（時間の区切り）を乗りきります。攻撃は勝手にしてくれます。
2. フェーズが終わるたびに、メフィーが強化を押し付けてきます。どれも強いけど、ちょっと癖があります。
3. 気に入らなければ「突き返し」で断れます（回数に限りあり。突き返すと敵が速くなります）。
4. 強化の組み合わせによっては、メフィーのうっかりで「うっかりコンボ」が起きます。
5. そのあと、敵の強化を3つから選びます。どれがましか、あんたが選んでください。
6. 5フェーズ目と10フェーズ目には強敵が出ます。フェーズ10を乗りきれば合格。
7. 合格すると、メフィーの「本気度」が上がって、もっと難しくできます。そのままエンドレスで続けることもできます。

## 操作

| | パソコン | スマホ |
| --- | --- | --- |
| 移動 | WASD／矢印 | 左のスティック（「設定」で方向キーにもできる） |
| 回避 | Space／左クリック（Shift・K・X でも） | 「回避」 |
| 選ぶ | 受け取るは Enter、敵の強化は 1〜3（クリックでも） | タップ |
| 一時停止 | Esc・P | 「一時停止」 |

結果は X に投稿できます。図鑑と実績、今までの記録は、このブラウザに保存されます。
